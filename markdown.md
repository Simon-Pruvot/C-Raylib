Aujourd’hui, j’ai travaillé sur le mode en ligne du jeu, qui permet maintenant à deux joueurs de jouer chacun sur leur propre machine via le même réseau WiFi, alors qu’avant le jeu était uniquement en local sur un seul PC. J’ai mis en place le système d’hébergement et de connexion avec l’échange d’adresse IP entre les joueurs, ainsi que le processus pour rejoindre une partie.

J’ai également modifié les écrans de menu pour ajouter les options “En ligne”, avec les actions pour héberger ou rejoindre une partie et afficher les informations nécessaires à la connexion.

Enfin, j’ai ajouté le mode 1 joueur avec un bot, permettant de jouer contre une IA au lieu d’un second joueur.
